The triage model

Every open finding is in exactly one bucket, decided by the first rule that matches, in this order. The bucket never changes a finding's state, its severity, or the open count. Stale data keeps being used and is shown as stale; missing data never makes a finding look safer or lowers a score.

Triage rules in order
RuleBucketWhen
I1IgnorableA kernel image that is installed but not the running kernel (older, or newer and not booted yet).
I2IgnorableA package with no runtime code of its source (linux-libc-dev, kernel headers).
K1Fix availableThe running kernel has a fix, and a kernel at or above it is installed: reboot.
K2Fix availableThe running kernel has a fix, and no such kernel is installed: install the new kernel package (manual; the update task installs no new packages), then reboot.
F1Fix availableThe advisory names a fixed version for this release.
F2Fix availableDebian's tracker has a fixed version for this release that the advisory data does not have yet.
I3, I4IgnorableDebian says this release is not affected, or marks it fixed at a version the host already has.
O1Low riskAn operator recorded a control, not expired and not suspended. (An accepted risk changes no bucket.)
N1Needs attentionIn the stored CISA Known Exploited Vulnerabilities list.
N2Needs attentionStored FIRST EPSS band high: 10% or more, staying until it falls below 7%.
I5IgnorableDebian rates it unimportant, once KEV data has been imported.
N3Needs attentionDebian: end-of-life, or removed from the release but still installed: no security support.

Wording, data, and accessibility

  • Hosts are *.example.lan. Advisory and CVE ids such as DEBIAN-CVE-2026-90777 are invented and name no real vulnerability; the KEV listing and EPSS scores shown are invented too. Package names are real Debian names with invented versions. Attack vectors are shown in words, with the CVSS vector as secondary text.
  • No badge says "secure", "safe", "clean", "compliant", or "protected"; every badge states its claim and scope. Nothing ranks people.
  • No JavaScript, no inline styles, and no external requests: the screens render offline and under the app's CSP (style-src 'self'). Bars and charts are SVG with geometry in attributes and colours in triage.css.
  • Buckets, tiers, signals, and badges are words plus shapes, never colour alone; meters are native <meter> with the numbers in text; charts have a title, a description, and a table of the numbers; sections are native <details>; forms have labels and errors beside the field.
