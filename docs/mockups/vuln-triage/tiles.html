How exposure is ranked

The tier comes first, and hosts sort by it. Points order hosts within a tier, so one known exploited host always ranks above a host with many medium findings.

A known exploited (KEV) advisory scores double, except in Ignorable. An advisory counts once per host, in its worst bucket, however many binary packages it matches. The values are a published constant (review question V13 asks about them).

Tier: Known exploited if a KEV advisory is in Needs attention or Fix available, or under a control; else Exposed, no fix if a critical or high needs attention; else Fixes waiting if a critical or high has a fix; else Low if any points; else Minimal.
