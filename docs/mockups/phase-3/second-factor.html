Lost your authenticator?

If you still have recovery codes, each one works once in place of a 6-digit code. Use one to move to a new phone.

If you have neither your phone nor a recovery code, it cannot be reset from the dashboard, on purpose: someone who took over your Google session could otherwise reset it too. Ask the server's administrator to run this on the server:

bin/rails second_factor:reset[example.operator@example.com]

It removes your authenticator and recovery codes and records an audit entry. You then set up a new one here.

Review Q25. Recovery codes: 10 codes, each usable once wherever a 6-digit code is asked for, including moving to a new phone, so a lost phone with saved codes needs no administrator. With neither, only the console reset works (P3-S09), which ADR 0006 asks for. Alternative: recovery codes only pass the step-up for one action and never replace the authenticator, so every lost phone goes through the console. The rake task name is a proposal.
