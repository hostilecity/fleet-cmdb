Review Q21. Codes named in the spec (interrupted, lease_expired, invalid_params, unknown_type, not_enabled_locally, not_allowed_locally) are used as given. protected_service, no_longer_allowed, package_manager_locked, and not_active_after_restart are proposed here and would be added to P3-S02's list. Each page shows the sentence first and the code small beside it. A refusal by the server at claim time is shown as Refused, the same state the agent uses, with "Server" as who refused.

Review Q22. Truncation keeps the start and the end with a marker between them, because the start shows what ran and the end shows how it finished.
