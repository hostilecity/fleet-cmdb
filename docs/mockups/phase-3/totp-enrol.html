Set up an authenticator app

Three steps: sign in with Google again, scan a code with your phone, and type the 6-digit code it shows.

  1. Sign in again

Scan this with your authenticator app

In the app, add an account and scan the code. It appears as Fleet CMDB (example.operator@example.com).

Cannot scan? Type this key instead (time-based, 6 digits, 30 seconds):

EXAM PLEK EYNO TREA LABC DEFG

The key is shown only on this page, only now. It is stored encrypted on the server and never shown again; if you leave without finishing, it is thrown away.

This checks that your phone and the server agree before the second factor is turned on.

Review Q26. The key is shown as a QR code and as text grouped in fours, both only on this page. The page sends no request anywhere else (the QR code is drawn by the server, never by a third-party service) and is served with no caching. This page expires 10 minutes after the Google sign-in, and leaving it without a correct code sets nothing up. Codes are 6 digits every 30 seconds with SHA-1, the setting every common app supports. Alternative: 8 digits, which some apps do not support.

Wrong code

That code does not match. Check that the time on your phone is set automatically, then type the newest code. Nothing is set up until a code matches.

Moving to a new phone

Move your second factor to a new phone

First type a code from your current authenticator app, or a recovery code. After a fresh Google sign-in you get a new key to scan; the old app stops working as soon as the new one is checked, and you get 10 new recovery codes.
