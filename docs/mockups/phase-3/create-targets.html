Review Q7. The server learns which task types each agent supports and has enabled (P3-A01), but not which services each VM allows, so a VM without nginx.service in its own list can only refuse at run time, as drawn in the blue notice. Alternative (recommended, needs a P3-A01 change): agents also report their local service allowlist, so those hosts are left out here with the reason "not in this VM's own allowlist" and nothing is sent to them. The agent still checks its own list either way.

Review Q8. Offline and stale hosts are kept, with a warning, because the task waits for the agent's next poll and expires after 24 hours if it never comes (FR-3.2). Alternative: leave out hosts that are offline now, so a batch only runs where it can run soon.
