Review Q16. "Run again on the hosts that did not succeed" starts the normal create flow at the confirmation with the same type, parameters, and those hosts filled in; it is a new batch, it is checked again from scratch, and it needs the second factor. It is a convenience only. Alternative: no shortcut; the operator starts a new task from scratch.

The batch outcome sentence is red when anything did not succeed, amber for a batch that only expired or was cancelled, and plain when every task succeeded. The wording, not the colour, carries it.
