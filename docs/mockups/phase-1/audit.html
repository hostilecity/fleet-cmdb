Times are exact UTC, not "2 days ago", so they line up with the From and To dates. Entries with the same second keep the order they were written (by id): the token for Lab sandbox was issued after its re-enrollment started.

Hosts link to the host page, retired ones included (hosts are never deleted). Other targets (onboarding requests, operators, settings) are plain text. An approval records the request, not the host: the host is created when the installer collects, and that entry names the approving operator.

Every value is shown as text: the Description above holds markup typed into a form and shows it literally. Fields are named in words; a key the page does not know is shown as recorded, in monospace. Secrets never appear here; a value the server filtered reads [FILTERED] (example). There is no way to add, edit, or delete an entry.
