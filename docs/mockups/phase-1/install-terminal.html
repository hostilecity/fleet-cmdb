Installer messages

What fleet-agent install prints in each case. Every failure says what happened and what to do next.

Rejected in the dashboard

Waiting for approval… expires in 8:10 (Ctrl-C to cancel) ✗ An operator rejected this request. Nothing was enrolled. The agent is installed but not running. To ask again: sudo fleet-agent install --server https://agent.fleet.example.lan To remove it: sudo fleet-agent uninstall

Not approved in time

Waiting for approval… expires in 0:01 (Ctrl-C to cancel) ✗ The request expired before anyone approved it. Nothing was enrolled. Run the same command again to get a new code.

Checks that fail before anything is installed

$ ./fleet-agent install --server https://agent.fleet.example.lan ✗ The installer must run as root. Run it again with sudo.
✗ Could not verify the certificate of agent.fleet.example.lan: certificate has expired. Nothing was installed. Check the server's certificate, or the VM's clock (it reads 2026-01-01 12:00 UTC).
✗ This VM runs Ubuntu 24.04 on x86_64. The agent supports Debian 13 on x86_64 only.

Unattended token problems

✗ The enrollment token is invalid, expired, or already used. Pre-register the host again in the dashboard for a new token. Nothing was enrolled.

Already installed

$ sudo ./fleet-agent install --server https://agent.fleet.example.lan fleet-agent 0.2.0 installer ✓ Already enrolled as "Build runner 2"; keeping its credential ✓ Updated 0.1.0 → 0.2.0, service restarted, first heartbeat accepted To enroll again from scratch: sudo fleet-agent install --reenroll

Exit codes

CodeMeaning
0Installed and running
2A check failed; nothing was installed
3Rejected by an operator
4Expired, or the token was invalid
5Server error; safe to run again

With --quiet only failures print; --json prints one machine-readable line for scripts. Colour is used only on a terminal, and every line starts with ✓ or ✗ so meaning never depends on colour.
