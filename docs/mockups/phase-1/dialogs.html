Confirmations

Destructive actions ask first (FR-S.4). Shown here open; in the app each opens over the host page.

Revoke the credential for Media server?

The agent on vm-01.example.lan is refused from its next request and the host stops reporting. To let it back in, issue a new enrollment token.

Issue a new enrollment token for Media server?

The host moves to pending until the agent redeems the new token. Its current credential keeps working until then, and the agent is told to re-enroll. Any earlier unused token stops working.

Retire Media server?

Retiring revokes the credential and removes the host from the fleet list and counts. Its inventory, history, and audit entries are kept. This cannot be undone.

Retire asks for the hostname because it is the only action that cannot be undone. Revoke and re-enroll can be reversed by issuing a new token, so a single button is enough.
