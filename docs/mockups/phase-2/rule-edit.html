What saving does

Press Preview first: it shows which hosts would change result and writes nothing. Saving then makes a new version, 3, which replaces version 2 as current. Every host's latest config snapshot is checked again against it, now, and any result that changes is recorded in that host's history. No agent is contacted. The change is audited with you as the actor and the before and after values. Saving without a change makes no new version.
