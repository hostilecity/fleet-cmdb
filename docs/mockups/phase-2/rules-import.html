Import rules file

Check a YAML or JSON rules file and see what it would change. Nothing is written until you apply it.

YAML or JSON, format version 1, at most 1 MiB. See the rule file format.

What happens next

The whole file is checked first. If every rule is valid you see what would be added, changed, and left alone, and you can apply it or cancel. If anything is wrong, nothing is imported and every problem is listed.

Cancel

Review Q13. The preview. Drawn: uploading shows the preview; "Apply import" then applies exactly the file that was previewed, which the server keeps for a short time (about 15 minutes) and drops when you apply, cancel, or it expires. Alternative: ask for the file again on the apply step, which stores nothing but makes the operator pick the same file twice and risks applying a file different from the one previewed. The first needs a short-lived store of an uploaded file; say if that is not acceptable.
