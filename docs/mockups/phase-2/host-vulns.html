Findings are stored one per installed binary package and advisory (decided in P2-S11), and the page groups them under their package, so a library built from the same source as another package appears as its own group. The advisory id links to the source advisory in a new tab; only http and https links are ever shown, with rel="noopener noreferrer". A finding with no recorded link shows "No link recorded". "Fixed in" reads "No fix available" when the source gives none. A resolved row says how it resolved (fixed, removed, withdrawn, or not affected) and when. A reopened row keeps both dates. Advisory text is escaped.

Decided in the P2-D01 review (Q16): findings are grouped by package, with the advisories nested under it. The package row shows the worst severity and how many findings it has; the severity filter still matches on a single advisory. The package page keeps the same grouping for one package across hosts.

P2-D07 review. Debian's triage sits inside the advisory cell, under the advisory's summary, as a quoted line that starts with "Debian:" (T1). It has no lamp, no pips, and no severity colour, so it reads as Debian's note and not as a second severity; the Severity column, the states, the chips' counts, and the summary tiles are exactly what they were. The worked example is DEBIAN-CVE-2026-19499 on libc6 (source package glibc): High by its CVSS score, open, no fix available for trixie, and Debian's note beside it. Other binary packages built from glibc (such as libc-bin) would have their own groups with the same line; they are left out to keep the example short. An advisory that names several CVEs gets one line per CVE (drawn on the package page). The tab shows the triage on open and reopened rows only; the resolved table is unchanged (T5). Debian's "not yet assigned" urgency is no urgency, so it is never shown as a value.

P2-D07 review. The dashed chip "Debian: no security update planned" narrows the current list to findings whose tracker entry has a no-DSA note (with no reason or reason postponed), and keeps the state, severity, and search filters. Its count is within the current state filter. Selected, it is drawn solid, like the state chips. Whether "ignored" belongs in it is T3.
