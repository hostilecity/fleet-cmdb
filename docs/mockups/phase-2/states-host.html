Four fact states, each a word plus a lamp shape (OK a green circle, unreadable an amber circle, unsupported a grey square, missing a hollow circle), and every state except OK has a reason in words. An unreadable, unsupported, or missing fact has no value, and the value cell says so; it is never blank and never a guess. A file or unit that does not exist is not an error: it is an OK fact whose value is "does not exist" or "not installed", and rules can test for it. Reasons come from the agent and are escaped.

Five result states. Not applicable means the rule is for another distribution or release; it says which, and is left out of the pass rate. Not readable means the fact could not be read (reason shown). Not evaluated means the rule is disabled, or the host has sent no config report; the reason says which. Lamps: Pass is a green circle, Fail a red diamond, Not readable an amber circle, Not applicable a grey circle, Not evaluated a hollow circle; the word is always there.

An observed value is stored as JSON and cut at 1,024 bytes; a cut value ends with "… (truncated from N bytes)" and the page says so in words, in an amber line under it, and points at the fact that holds the whole value. The box scrolls and can take keyboard focus, so a long value never widens the page. Reasons are cut at 512 characters. Agent-reported text is always escaped: the second row shows a hostile string as text. Long fact values (such as 64-entry cipher lists) wrap with overflow-wrap: anywhere.
