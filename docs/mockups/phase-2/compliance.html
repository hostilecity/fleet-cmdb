Review Q9. Sorting by worst, and where hosts that are not evaluated go. Drawn: "worst first" orders hosts by their critical findings (CIS failures plus vulnerabilities together), then high, medium, low, and unknown, then by lowest pass rate. Hosts with nothing evaluated at all sit below everything, shaded and labelled, so an unknown host is neither at the top as an emergency nor mixed in with the clean ones. Alternative: put not-evaluated hosts first, because an unknown host is a risk too. Status filter "Not evaluated" lists only them either way.

Three things look different on purpose. 0 in grey is a severity with no open findings on a host that has some. None open is an evaluated host with no findings at all. Not evaluated with its reason is a host the server could not judge (AC: "Not evaluated" and "zero findings" are never shown the same way). Column headers carry severity as words, and every number is a link target on the host page, not colour.

The pass rate uses the definition on the host page (Q3): passed ÷ (passed + failed + not readable).
