Every change is a word and a symbol, never colour alone. Direction comes from dpkg's version order, so 1:7.8p1-5 to 1:7.8p1-4 is a downgrade although the strings sort the other way. "Cannot compare" is shown when either version is not a valid dpkg version; it is never guessed as an upgrade. "Source changed" is a package whose version stayed the same but whose recorded source package changed. The Findings column links the change to the vulnerability findings it opened, resolved, or reopened (AC-2.4); it is an addition to the P2-D03 scope and can be dropped.
